# VegamShare 0.4.1

WhatsApp files open right away, and the Windows app can start with Windows.

## What's new
- **WhatsApp files open faster (Android):** the list fills in while the phone is still being
  scanned, newest first, instead of waiting for every file. Opening the screen again during the
  same session shows the last list at once and refreshes it in the background of that screen.
- **Start with Windows:** the installer now offers *Start VegamShare with Windows* (ticked by
  default). VegamShare then starts minimized in the tray, ready to receive. Turn it off any time
  in Settings → *Start with Windows*.

## Upgrading
- **Android:** install over 0.4.0 (or tap *Update* in Settings → *Check for updates*); your data
  is kept.
- **Windows:** run the new installer over 0.4.0 (or update from inside the app); settings and
  saved devices are kept.
